# Modern LMS — agent instructions

Before any change, read `docs/RULES.md` and follow it. For non-trivial work also read
`docs/PRD.md`, `docs/ARCHITECTURE.md`, `docs/DESIGN.md`, `docs/TASKS.md`, `docs/MEMORY.md`, `docs/DECISIONS.md`.

- Work on one task ID from `docs/TASKS.md` at a time; state a plan before touching >3 files.
- Gate before done: `npm run check` (typecheck → lint → test → build).
- After a task: update `docs/TASKS.md` and `docs/MEMORY.md`, then commit (`feat: … (T-0NN)`).
