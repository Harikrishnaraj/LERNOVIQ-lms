Platform & implementation approach

Technology foundation

The documented deployment design uses a Next.js application, container-based deployment with Docker, Caddy-managed HTTPS and a GitHub Actions release workflow. It provides for a separate content origin to support multi-frame SCORM packages, scheduled reporting jobs, and Supabase authentication configuration.

These are architectural provisions documented in the deployment guide, not independently verified end-user features.
